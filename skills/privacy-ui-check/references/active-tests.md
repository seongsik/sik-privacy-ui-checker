# 능동 시험 항목별 절차

능동 시험은 테스트 계정의 상태를 바꾸거나 접속기록·메일을 남긴다. 항목마다 아래 **승인 문구**를 그대로 보여 주고
사용자 승인을 받는다. 승인 없이는 시험하지 않고 `점검불가(미승인)`로 남긴다. 입력은 사용자가 격리 브라우저 창에서 직접 한다.
실행 도구는 `scripts/active_test.py` (SKILL.md 5단계). 대상 요청(`--target`)은 메뉴맵·수집물의 네트워크 기록에서 찾는다.

공통 규칙:
- 운영 관리자 계정·실제 고객 계정으로는 하지 않는다. 점검 전용 테스트 계정만.
- `--max-attempts` 는 승인 문구에 적은 횟수와 같아야 한다.
- 시험이 끝나면 계정 원상복구(잠금 해제, 설정 되돌리기)를 사용자에게 안내한다.
