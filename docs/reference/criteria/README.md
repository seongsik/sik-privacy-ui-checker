# 점검 기준 (초안)

웹서비스 개인정보보호 점검 스킬이 판정에 쓰는 점검 항목 모음이다. 아래 원문에서 subagent가 범위를 나눠 추출했고, 아직 검토·확정 전이다.
설계가 확정되면 스킬이 읽는 형식(데이터 파일)으로 옮긴다.

## 항목 형식

항목마다 `### <ID> <항목명>` 아래 11개 필드: 근거, 요구사항, 적용조건, 점검유형, 점검위치, 점검방법, 양호기준, 취약기준, 조치방안, 증적, 비고.

- ID: 접두어-조-항-일련번호. 조의2는 B(조의3은 C …), 항이 없는 조는 `00`. 예: `SAFE-05-06-01`, `SAFE-06B-01`, `PIPA-28H-01`.
- 점검유형:
  - **관찰**: 브라우저에서 읽기 전용으로 확인.
  - **능동(승인)**: 테스트 계정으로 상태를 바꾸는 시험. 항목마다 승인받고 입력은 사용자가 한다.
  - **서면**: 화면으로 확인 불가. 보고서에 "점검불가(서면·인터뷰 확인 필요)"로 남긴다.
- 비고에 근거 강도를 적었다: 법령 의무 / 안내서 예시·권고 / 외부 참고(판정 근거로 쓰지 않음).

## 확인·결정이 필요한 점

각 파일 끝 `## 추출 메모`에 상세가 있다. 묶으면 다음과 같다.

### 원문 확인
1. **시행일**: 안내서는 고시 제2025-9호 부칙에 따라 제4조①12·13호, 제5조①⑥, 제6조②, 제8조 개정분을 2026.10.31.~11.1. 시행으로 적는다. 현행 고시 제2026-9호 부칙은 제15조제5호·제18조(2027.1.1.)만 정한다. 점검일 기준 적용 여부를 원문으로 확인해야 한다.
2. **원문에 없는 별표·위임 고시**: 고시 [별표](제6조의2②), 영 별표 1(CPO 자격), 동의 화면 글자 크기(9pt·20%)를 정한 「개인정보 처리 방법에 관한 고시」, 망법 영 별표 6(광고 표시), 청소년유해매체물 표시 고시, 동의 안내서, 처리방침 작성지침.
3. **안내서 내부 불일치**: 위험도 분석 5번 교육 횟수(연 2회/연 1회), FAQ-48 공공시스템 유형표(p.154, 텍스트 추출로 칸이 섞임).

### 판정 기준
4. **법정 수치가 없는 항목**: 비밀번호 규칙, 인증 실패 횟수, 세션 차단 시간, TLS 버전, 마스킹 위치. 외부 참고값(구 해설서 2종 10자리/3종 8자리, 5회, 10~30분, TLS 1.2 이상, NIST SP 800-63B)을 쓸지, "개선 권고" 같은 별도 등급을 둘지.
5. **해석에 따른 판정 표기**: URL 속 비밀번호, 혼합 콘텐츠, localStorage 토큰, 관리자 브라우저 저장소 개인정보.
6. **정성 판정**: 최소 수집, 본인 화면의 고유식별정보 전체 표시, API 과다 응답, 자동화된 결정의 "중대한 영향", 14세 미만 자기 체크 확인, 외부 도메인 호출을 위탁·국외 이전 근거로 쓰는 기준.
7. **권고 수준 항목**: 처리방침 명칭·강조 표시, 회원정보 수정 시 추가 본인확인, 다운로드 사유 입력(공공시스템 외).

### 점검 범위·운영
8. **상태를 바꾸는 시험**: 비밀번호 저장·재설정, 계정 잠금, 수신설정 변경, 탈퇴·정정, 다운로드·검색 실행(접속기록·메일 발생).
9. **체크박스 해제 관찰**: 제출 없이 진행 버튼 활성 여부만 보는 것을 관찰로 허용할지.
10. **적용조건**: 이용자 수·매출·공공기관 여부는 화면으로 알 수 없다. 사전 질문지로 받을지.
11. **범위 밖 후보**: 망법 콘텐츠 규제(NET-44H·44I·44L·44N), 영상정보처리기기(STD 제3장), 공공기관 파일 등록. 일괄 "해당없음" 처리 여부.
12. **외부 도구**: TLS 버전·암호군은 브라우저로 볼 수 없다. 사용자가 실행하는 openssl 또는 외부 진단 서비스(도메인 제3자 전달).
